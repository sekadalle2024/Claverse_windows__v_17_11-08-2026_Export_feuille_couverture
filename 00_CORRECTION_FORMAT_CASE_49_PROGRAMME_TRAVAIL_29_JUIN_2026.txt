📋 CONTEXTE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Nouveau workflow n8n qui retourne un format JSON spécifique avec la structure:
[{ "output": "`json\n{...}\n```" }]

Le JSON est enveloppé dans un bloc markdown avec un backtick simple initial (`json)
suivi de triples backticks (```), ce qui causait une erreur de parsing.

🔴 PROBLÈME INITIAL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Erreur: "Unexpected token '`', \"`json\n{\"... is not valid JSON"

Le code existant ne gérait que le format avec triples backticks (```json)
mais pas le backtick simple initial (`json) présent dans la réponse.

✅ SOLUTION APPLIQUÉE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Amélioration du nettoyage des backticks en 4 étapes séquentielles:

1. Détection améliorée:
   - Recherche de "```json" OU "`json" au début

2. Étape 1 - Backtick simple initial:
   - Si le contenu commence par "`json", retire ces 5 caractères
   - Exemple: "`json\n{...}" → "{...}"

3. Étape 2 - Triples backticks:
   - Retire "```json" au début et "```" à la fin
   - Utilise des regex avec flag global et multiline

4. Étape 3 - Backticks résiduels:
   - Retire tous les backticks au début et à la fin
   - Nettoie les cas edge avec plusieurs backticks

5. Étape 4 - Parsing JSON:
   - Parse le JSON nettoyé
   - Transforme en FORMAT 4 pour traitement standard
