🔧 MÉTHODES DE DÉBOGAGE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Dans la console du navigateur :

1. Vérifier si le menu est initialisé :
   └─► window.initContextualMenu

2. Forcer l'initialisation :
   └─► window.initContextualMenu()

3. Forcer avec reset complet :
   └─► window.forceContextualMenu()

4. Nettoyer le menu :
   └─► window.cleanupContextualMenu()

5. Voir les logs d'initialisation :
   └─► Chercher dans la console :
       "🎯 Initialisation du menu contextuel ClaraVerse"
       "✅ Menu contextuel initialisé avec succès"
