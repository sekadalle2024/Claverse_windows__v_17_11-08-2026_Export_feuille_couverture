    🆘 EN CAS DE PROBLÈME
================================================================

ERREUR: "Pas de dépôt Git trouvé"
→ Solution: Exécutez d'abord: git init

ERREUR: "Impossible de se connecter au repository"
→ Solution: Vérifiez vos identifiants GitHub
→ Commande: git config --list

ERREUR: "Push échoué"
→ Solution 1: Relancez le script (il reprendra où il s'est arrêté)
→ Solution 2: Utilisez GitHub Desktop (très fiable pour gros projets)

ERREUR: "Authentication failed"
→ Solution: Configurez vos credentials:
   git config --global user.name "VotreNom"
   git config --global user.email "votre.email@example.com"
