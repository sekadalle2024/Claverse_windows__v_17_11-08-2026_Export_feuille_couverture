  │  ❌ AVANT (CODE ORIGINAL)      │  ✅ APRÈS (CODE CORRIGÉ)       │

  1️⃣  POSITION: STICKY
      • Essentiel pour le figement
      • Nécessite left défini
      • Fonctionne avec overflow-x: auto

  2️⃣  CALCUL DES LARGEURS
      • offsetWidth > getBoundingClientRect
      • Reflow forcé avant calcul
      • Fallback si width = 0

  3️⃣  Z-INDEX OPTIMISÉ
      • 100 pour colonnes figées
      • Passe au-dessus du contenu défilant
      • Évite les conflits avec UI

  4️⃣  BACKGROUNDS OPAQUES
      • Évite transparence
      • S'adapte au thème (clair/sombre)
      • Alternance lignes paires/impaires

  5️⃣  MARQUEURS VISUELS
      • Bordure rouge 3px
      • Ombre portée
      • Classe CSS .freeze-last-col
