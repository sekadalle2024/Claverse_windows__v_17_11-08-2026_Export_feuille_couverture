PROBLÈME:
---------
L'endpoint n8n "https://fpb7ab9h.rpcl.app/webhook-test/integration" retourne 
une réponse dans un format différent des autres endpoints:

Format reçu:
[{
  "output": "`json\n{\"Sous-section A\": \"...\", \"Sub-items\": [...]}\n```"
}]

Le JSON est encapsulé dans:
1. Un array [{...}]
2. Une propriété "output"
3. Des backticks markdown `json ... ```
4. Parfois des échappements excessifs (\\n, \\", etc.)

RÉSULTAT ACTUEL:
---------------
ClaraApiService.tsx ne détecte pas ce format et affiche une erreur :
{
  "error": "Unexpected token '`', \"`json\n{\"... is not valid JSON",
  "raw": "..."
}
