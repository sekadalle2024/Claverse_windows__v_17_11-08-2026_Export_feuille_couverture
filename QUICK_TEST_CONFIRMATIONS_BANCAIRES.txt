### 3. Créer une table principale

#### ✅ Vérification 3: Alignement
- **Attendu**: Les 9 cellules s'alignent avec la colonne "Ecart"

## 🔍 COMMANDES DE DEBUG

### Voir le stockage
```javascript
crossRefCommands.showStorage();
```

### Retraiter toutes les tables
```javascript
crossRefCommands.processAll();
```

### Restaurer les cross références
```javascript
crossRefCommands.restoreAll();
```

### Effacer le stockage (avec confirmation)
```javascript
crossRefCommands.clearStorage();
```

## 🐛 PROBLÈMES COURANTS

### Problème 1: Pas de cross référence créée
**Cause**: Nature de test non détectée
**Solution**: Vérifier que la table 2 contient "Confirmation" ou "bancaire"

### Problème 2: Mauvais nombre de colonnes
**Cause**: Autre condition détectée en premier
**Solution**: Utiliser "Confirmation bancaire" explicitement

### Problème 3: Cross référence en double
**Cause**: Table déjà traitée
**Solution**: Recharger la page ou supprimer via menu contextuel

### Problème 4: Sauvegarde ne fonctionne pas
**Cause**: localStorage désactivé ou quota dépassé
**Solution**: 
```javascript
// Tester localStorage
crossRefCommands.showStorage();
```
