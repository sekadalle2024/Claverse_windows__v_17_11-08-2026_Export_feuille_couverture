fix: Désactive ouverture automatique menu contextuel au survol

Le menu contextuel s'ouvrait automatiquement après 300ms de survol
d'une table, ce qui était intrusif et non standard. Le comportement
attendu est une ouverture uniquement au clic droit.

Modifications:
- Commenté le setTimeout dans handleTableHover() (menu.js:~9638)
- Ajout de commentaires explicatifs dans le code
- Conservation des événements mouseover/mouseout pour la fermeture
- Aucun effet de bord sur les autres fonctionnalités

Comportement après correction:
- Survol de table: aucune action
- Clic droit: menu s'affiche normalement
- Toutes les actions du menu fonctionnent
- Fermeture automatique préservée

Fichiers modifiés:
- public/menu.js

Documentation:
- 8 fichiers de documentation créés
- Guides de test et dépannage fournis
- Voir 00_RECAP_SESSION_CORRECTION_MENU_27_AOUT_2026.txt
